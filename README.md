
# Task Management API

A simple API for managing tasks in your project.


## Project Overview
This project make utilize of technologies such a node js, express js,  mongodb Joi, it uses basic server setup with router for routing, controller for handling api logic and models to describe database structure. It uses Joi for data validation to ensure data integrity. All the apis are tested through Insomnia. Data inserted in the database are dummy data generated by ChatGPT.

## Endpoints

### `GET /api/tasks/`

Gets tasks with optional filtering.

**Examples:**
- `GET /api/tasks/` - Get all tasks
- `GET /api/tasks/?assignee=Henry&status=assigned&priority=low` - Filter by multiple criteria
- `GET /api/tasks/?priority=low` - List all low priority tasks

**Pagination:**
- `GET /api/tasks/?limit=10` - Show 10 tasks per page
- `GET /api/tasks/?page=2&limit=5&order=asc` - Get page 2 (tasks 6-10) in ascending order
- `GET /api/tasks/?page=2&limit=5&order=desc` - Get page 2 in descending order

### `POST /api/tasks/`

Create a new task.

### `PUT /api/tasks/`

Update an existing task.

### `DELETE /api/tasks/`

Delete a task by ID.

## Basic Usage

1. Create tasks using POST
2. View tasks using GET with filters as needed
3. Update tasks using PUT
4. Remove tasks using DELETE

## Usage Instructions

1. Clone this repository:  
   `git clone https://github.com/BishwasXD/EBPearls-Task-Management.git`

2. Navigate to the project folder and install dependencies:
   ```bash
   cd EBPearls-Task-Management
   npm install
3. Create a MongoDB database:
- Visit MongoDB Atlas and create a free plan
- Copy the URI and add your username and password
- Create a `.env` file in the root directory
- Add the MongoDB URI to your `.env` file:
  ```
  URI=mongodb+srv://<username>:<password>@cluster0.example.mongodb.net/Task
  ```
- Check the database connection before proceeding

4. Start the server
5. Use Insomnia or Postman to test the APIs

**Note:** node version used v18.20.8
